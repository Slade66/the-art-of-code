- **有什么用？**
	- Loopback 让设备发出的数据在还没进入外面的网络之前，就被操作系统拦截并送回给自己。
- **假设没有 Loopback。**

- **操作系统中的 Loopback**
	- 在你使用的电脑或手机上，都有一个虚拟的 Loopback Interface（回环接口）。
		- **标准的 IPv4 地址：**`127.0.0.1`
		- **标准的 IPv6 地址：**`::1`
		- **主机名：**`localhost`
	- **有什么用？**
		- **本地开发调试：**输入 `http://127.0.0.1:8080` 就能访问自己电脑上运行的服务，而不需要联网。
		- **协议栈自检：**如果你 `ping 127.0.0.1` 失败，说明你电脑的 TCP/IP 协议栈崩溃了；如果成功但上不了网，说明问题出在网线、路由器或运营商那里。
- **网络设备（路由器/交换机）中的 Loopback**
	- 在网络设备上，Loopback 是一个虚拟的逻辑接口（Logical Interface），它不依赖物理接口，只要不关机，Loopback 接口永远是 `Up` 状态，永远不会因为网线拔掉就消失。
	- **有什么用？**
		- **管理地址：**物理接口可能因为网线被踢掉而变成 `Down` 状态，但 Loopback 永远是 `Up` 的。因此，管理员常用它的 IP 作为设备的管理地址。只要设备没死，这个 IP 就能 ping 通。
		- **隧道终点：**在建立 VPN 或 MPLS 隧道时，通常把 Loopback 地址作为隧道的起点或终点。
		- **路由协议的 Router ID：**在运行 OSPF 或 BGP 协议时，路由器需要一个唯一的 ID。使用 Loopback 地址作为 ID 可以保证协议运行的稳定性。
- **A 主机的回环地址能被 B 主机 ping 通吗？**
	- **为什么你不能 ping 通别人电脑的 127.0.0.1？**
		- `127.0.0.1` 是一个非路由地址。
		- **内部消化：**每一台电脑都认为自己是 `127.0.0.1`。当 A 主机发起一个指向 `127.0.0.1` 的请求时，数据包在到达网卡驱动之前，就会被 TCP/IP 协议栈拦截并直接转回给 A 自己。
		- **无法上路：**这个数据包永远不会出现在物理网线上。既然 A 连发都发不出去，B 当然也就收不到，更没法回应。
	- **为什么可以 ping 通网络设备的 Loopback 地址？**
		- **非保留地址：**通常会配置一个私有局域网 IP，而不是以 127 开头的地址。这里使用的 Loopback 地址属于可路由的网段，并不在 127.0.0.0/8 这个保留地址范围内。
		- **必须有路由：**必须在 B 主机以及中间经过的路由器上，都配置有能够到达 A 主机 Loopback IP 的路由条目。
